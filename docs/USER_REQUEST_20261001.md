## 一、先明确：现在需要突破的是哪一层

我核对了仓库最新记录。加强后的最短合法完整码流分别是 Paris **285,056 B**、Tokyo **369,068 B**、Lagos **230,257 B**、São Paulo **312,146 B**，全部来自 UInt16 byte-shuffle＋LZMA6 无损编码。SZ3、QPET、MGARD 已有实际控制，其中 MGARD 已产生非平凡的合法重建，只是文件仍较大。下一轮不需要重新搭建这些基线。

已有 clipping 实验也把问题定位清楚了：部分前缀压缩结果原本具有求和保证，恢复出的像元却越界；裁剪后范围合法，区域误差显著放大。**现在缺的是能够直接生成合法场的有效量化机制。**

2×2 条件字母表解决了可行性，但固定三个边际会限制可丢弃的信息。可以给出一个简单上界：每块只改变一个自由度，且变化不超过 \(M\)，同一解码块最多对应 \(2M+1\) 个源块。因此，对 \(N\) 个像元，

\[
H(X\mid C)\leq \frac N4\log_2(2M+1).
\]

在 \(M=25/250\) 时，这一信息丢弃上限约为 **1.42/2.24 bit/pixel**。它不是实际文件节省的上界；边际表示本身的冗余还会影响码长。

这说明下一条主线应当**解除局部边际必须精确保留的限制**。原推导已经明确承认 transportation 循环、Haar 细节和条件标量量化的经典性质，继续围绕这些成分扩展，很难单靠理论包装获得实质提升。

## 二、新候选：大部分像元粗化，少数位置保留细余数

设原始场为

\[
X\in\{0,\ldots,U\}^{H\times W},\qquad U=10000.
\]

我们直接寻找合法重建场 \(Y\)。给定步长 \(q\)，优先让输出落在

\[
0,q,2q,\ldots,\left\lfloor U/q\right\rfloor q
\]

这些粗格点上。需要时允许输出其他合法整数，并付费保存细余数。

令

\[
Y=qZ+r,\qquad 0\le r<q.
\]

解码端只需要恢复 \(Z,r\)，然后计算 \(Y=qZ+r\)。**不需要原图、前缀误差状态、优化路径或每个小块的原始边际。**

初步优化目标是

\[
m(Y)=\#\{(i,j):Y_{ij}\bmod q\neq0\},
\]

即需要细精度的位置数。最终仍要比较

\[
L(Z)+L(r)+L(\text{元数据、掩码、文件头、校验}).
\]

这里有一个必须保留的区分：**细位置少，有利于压缩余数；商数组 \(Z\) 的相关性可能同时变差。** 因此，最小化 \(m(Y)\) 是机制目标，不能直接称为实际码长最优。

### 同时控制全部矩形

定义二维累计误差

\[
E=S(Y-X),
\]

其中 \(S\) 是二维前缀和。取

\[
B=\left\lfloor\varepsilon/4\right\rfloor,
\qquad |E_{ij}|\le B.
\]

任意矩形误差由四个角点的 \(E\) 值组成，立即得到

\[
\left|\sum_R(Y-X)\right|\le4B\le\varepsilon.
\]

四角公式属于基础工具。真正需要解决的是：**如何在这个约束下，找到合法且容易编码的 \(Y\)。**

## 三、关键算法：把合法量化写成可快速求解的整行路径

固定已经处理的行。记上一行累计误差为

\[
u_j=E_{i-1,j},\qquad u_0=0.
\]

当前行上一列状态为 \(a=E_{i,j-1}\)，当前状态为 \(b=E_{i,j}\)。由混合差分恒等式，

\[
\boxed{
Y_{ij}
=
X_{ij}+b-a-(u_j-u_{j-1})
}
\]

这条式子把三个要求放进同一个转移：

- \(a,b\in[-B,B]\)，控制累计误差；
- \(0\le Y_{ij}\le U\)，保证物理范围；
- 保护位置只允许 \(Y_{ij}=X_{ij}\)。

转移代价首先是 \(1[Y_{ij}\bmod q\neq0]\)，再用 \(b^2\) 固定并列解。整行动态规划可以找到当前入边条件下，细精度位置最少的合法重建。

### 1. 完整可行性可以证明

令整行的状态直接沿用上一行：

\[
b=u_j,\qquad a=u_{j-1}.
\]

代入转移式，得到

\[
Y_{ij}=X_{ij}.
\]

因此，每一行至少有“复制源行”这一条完整可行路径。逐行归纳后，**所有满足输入合同的整数场都存在合法输出**。粗化失败的位置有细整数选择，不会卡死，也不需要解码后裁剪。

这个证明没有保证细位置一定稀少。稀少程度正是后续需要研究和测量的对象。

### 2. 转移复杂度可以从 \(O(B^2)\) 降到 \(O(B)\)

令

\[
t=X_{ij}-(u_j-u_{j-1}).
\]

固定当前状态 \(b\)，合法前驱满足

\[
a\in[t+b-U,t+b]\cap[-B,B].
\]

粗格点转移进一步要求

\[
a\equiv t+b\pmod q.
\]

于是，每一步只需要求两种区间最小值：完整前驱区间的最小值，以及指定同余类中的最小值。随着 \(b\) 增加，区间端点单调移动，可以用单调队列求解。

**这一加速已经实现，并与二次复杂度参考实现逐项核对。** 当前整场初次扫描复杂度为

\[
O(HWB),
\]

单行回溯空间为 \(O(WB)\)。复杂度依赖数值预算 \(B\)，不能写成与精度无关的线性算法。

### 3. 还能精确判定“一整行是否可以完全粗化”

这一点比简单地报告“细位置很少”更有解释力。

若整行输出都是 \(q\) 的倍数，令累计输出为 \(qK_j\)。定义

\[
v_j=\sum_{\ell\le j}X_{i\ell}-u_j,
\]

则

\[
A_j=\left\lceil\frac{v_j-B}{q}\right\rceil,\qquad
C_j=\left\lfloor\frac{v_j+B}{q}\right\rfloor,
\]

并要求

\[
A_j\le K_j\le C_j,\qquad
0\le K_j-K_{j-1}\le Q,\quad Q=\lfloor U/q\rfloor.
\]

如果上一列可达累计值构成区间 \([L,H]\)，下一列的可达区间恰好是

\[
\boxed{
[\max(A_j,L),\ \min(C_j,H+Q)].
}
\]

从 \([0,0]\) 出发，区间始终非空，当且仅当存在完全粗化的整行输出。这个判据只需要 **\(O(W)\)** 时间。

它已经实现，并在 **1,000 个随机行**上与完整动态规划的“最少细位置是否为零”判决一致。它能明确区分：

**当前入边下确实需要细精度，还是某个优化器没有找到已有的粗解。**

这个必要充分条件仅针对固定入边，不能外推成二维全局必要充分条件。

## 四、继续深化的重点：让前面行也能重新释放误差空间

当前初次扫描的弱点很明确：前面行的选择会影响后面行。每行条件最优，不代表整场最优。

下一项值得做的算法工作，是在已有合法场上进行**保持整场可行的行更新**。这一部分我完成了推导，尚未实现。

假设修改第 \(i\) 行，令其累计改变量为

\[
s_j=\sum_{\ell\le j}(Y'_{i\ell}-Y_{i\ell}).
\]

所有后续行 \(k\ge i\) 的累计误差都会变成

\[
E'_{kj}=E_{kj}+s_j.
\]

保持整场前缀预算的精确条件为

\[
\boxed{
-B-\min_{k\ge i}E_{kj}
\le s_j\le
B-\max_{k\ge i}E_{kj}.
}
\]

这个区间总包含零，宽度不超过 \(2B\)。因此，可以继续使用前面的区间与同余类结构求解。

这一推导的价值在于：**修改某一行时，同时考虑它对后面所有行的影响。** 无需为每个候选重新检查全部矩形。

通过维护后缀最小值、最大值和累计平移量，目标是把每遍更新维持在 \(O(HWB)\)。如果精确最小化细位置数，整场细位置数不会增加；若再以全场前缀平方和作为第二目标，只接受严格改善，就能避免等值循环。

这里仍不应承诺实际文件长度单调下降。**更新后必须重新编码，记录目标下降但字节上升的情况。**

## 六、原创性应落在哪里

这条路线需要与已有工作逐项比较，不能用新名称代替查新。

矩阵舍入与区域 discrepancy 已有系统研究，包括特定区域族上的有效算法；二维 Sigma–Delta 也研究了误差扩散、稳定性和重建误差。**“协调像元误差”本身不能作为新颖性。**[应用数学学会](https://epubs.siam.org/doi/10.1137/S0097539702417511)

Trellis 搜索用于量化同样是成熟思想，DCC 2020 已有 trellis-coded image compression 工作。[arXiv](https://arxiv.org/abs/2001.09417) QPET 则已经包括 QoI 约束分析、误差界调节、验证以及额外编码不合格数据，**“少量细精度修正”单独也不够。**[VLDB](https://www.vldb.org/pvldb/vol18/p2440-liang.pdf)

这篇稿件可以争取的贡献组合应当是：

**有界科学场的粗化可行性刻画 → 利用范围区间与同余类结构的快速精确行解 → 保持整场可行的更新 → 真实科学源上的完整码流改善。**

其中，四角公式作为基础，2×2 作为控制。正文中心放在**什么情况下需要细精度，以及怎样以可接受的计算成本减少它**。

目前还没有完成逐定理、逐算法的排重，因此不应提前写“首次”或“新范式”。

## 七、下一轮执行计划：先做决定性实验，再决定是否扩展

### 阶段 A：把现有原型接入完整码流

先用当前已经运行的初次扫描，不等待后续改进器。

冻结 \(q=20/200\)、行顺序、并列规则、两路编码方式、文件字段和资源上限。复用仓库的独立解码、mask、geo、校验及全部矩形验证接口。**所有判断从最终独立解码的场开始。**

同时保留同格式 \(Y=X\) 的无损归因控制，以及固定的 2×2 边际控制。这样才能分清：收益来自低位信息被删除，还是单纯换了一种更好的无损表示。

这里还要明确一个应用语义：**有效零与 NoData 不同。** 当前候选允许有效零在预算内变为小正数，NoData 必须保持。应加入“所有源零精确保留”的消融，检查压缩收益是否过度依赖改变零支持。应用若要求零支持精确，就应在主合同中固定这一要求。

### 阶段 B：在原四窗口上决定是否继续

下一轮建议预先固定以下晋升标准，**这些是本计划的新建议值，不是历史门槛**：

每个预算至少 **3/4 个源严格胜出**；该预算四源总字节至少减少 **10%**；任一源膨胀不超过 **5%**；所有实例完整满足范围、缺测和全部矩形合同。

以当前基线计算，每个预算的四源总量要从 **1,196,527 B** 降到约 **1,076,874 B 以下**。独立报告方法结果，不把“加入基线候选池后取最小值”当作独立算法成绩。

失败后按码长分解决策：细位置很多，检查可行性与扫描顺序；细位置很少但文件仍大，检查商数组相关性和固定开销。**不要一看到失败就同时换步长、换编码器、换数据。**

### 阶段 C：只补失败原因真正需要的优化

若主要问题是行间顺序耦合，再实现第四节的全场可行更新。先做慢速全量重算对照，再固定最多两轮行列交替，保存每个检查点的目标和真实码长。

若细位置减少始终不能带来字节减少，下一步才讨论固定码长模型下的优化，并重新推导复杂度。不能沿用 \(0/1\) 费用的快速求解证明，却宣称对任意熵编码器码长最优。

若当前初次扫描已经通过阶段 B，优先开展真实留出，不为增加章节而强行添加复杂模块。

### 阶段 D：通过后再扩展证据和写稿

四个现有窗口都是开发数据。通过后再冻结新的独立地理窗口，保持实现与预算不变，按**地理源**汇总结果。真实缺测、低建成密度、高建成密度都需要覆盖；目前的 100/1000 m² 预算还需要与实际用途对应。

规模扩展还要防止一个错误：**不能把多个各自满足 ε 的小块直接拼起来，就宣称大图也满足同一个 ε。** 跨块矩形误差可能累积。大场量化需要同一个全局累计误差约束；熵编码可以分块，误差状态不能未经证明地重置。
