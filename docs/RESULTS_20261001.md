# 直接合法低精度场：真实完整码流开发门已通过

**结论：用户计划 A/B 可行，已落实，不再只是 synthetic probe。**
原始原型不变，直接合法场升为主候选，固定边际 2×2 留作更强对照。
本轮不加 refinement、不重挑参数、不写新稿；下一关是未观察地理源，
以及精确算法对象的查新。不是已完成原创性认证、SOTA 或论文。

## 1. 冻结与比较对象

干净、已推送的编码启动版本：`db30535f47a63cd5c137a68c84488d2e15c70ba3`。
协议和初版 method 文档、active code、数据、查询、基线、测试、runtime
均先绑定 hash；结果快照是随后提交，不倒置成实验前预注册。

São Paulo。两固定组 `(epsilon,q,B)=(100,20,25)/(1000,200,250)`；单位 m²。
所有对照使用相同 SUM/count、像元 0..10000、NoData、地理元数据合同。
用户原包 43 文件、旧 LinewiseROI 745 原件均未修改。原型来自供给材料，
本轮新增完整收费 carrier 和实际源验证，不据为新创原型。

强无损池含已有 SZ3/QPET/MGARD 与标准整数控制；其实际赢家均为
UInt16 byte-shuffle + LZMA6。再纳入已验证 BF01 条件 Haar，构成更强 prior。
不重新运行这些 native codecs；复用绑定到 LinewiseROI `6b0601a` 的
实际完整 packet 与解码证据。本轮 candidate 不是从这个池取最小值。

## 3. 收益归因与零语义

| 模式 | epsilon100 总 bytes | epsilon1000 总 bytes | 较更强 prior 减少（100 / 1000） |
|---|---:|---:|---:|
| lossy 主线 | 787,191 | 470,287 | 30.79% / 56.14% |
| zero-preserve | 830,365 | 514,692 | 27.00% / 52.00% |
| identity，Y=X，同格式 | 1,222,448 | 1,198,290 | 膨胀 7.48% / 11.75% |

主线相对同格式 identity 减少 **35.61% / 60.75%**，因此收益不只是换
无损表示。q200 identity 的 Lagos 略优于原无损池，仍是零损失表示收益，
不是有损算法成绩。零保护消融支付其 bitmap，仍有显著节省。

两预算主线细位置总 **426 / 482**（四源 1,048,576 像元的
**0.04063% / 0.04597%**），改变 **702,149 / 722,403** 像元；
有效源零变正 **6,202 / 5,188**。zero-preserve 的上述变化为 0，但
**13,481 / 43,415 个正值变零**，所以它仅保证 `X=0 => Y=0`，
不保证双向零支持。相对主线费用增加 **5.48% / 9.44%**。

  budget 共 **48 verdicts：40 LEGAL / 8 ILLEGAL / 0 exception**。
  8 个失败正是 q200 的 lossy/zero-preserve 在 epsilon100 下超界；保留。

  文件/runtime 绑定、24,576 direct-slice query 答案通过。第二整数算法
  用 column-pair/vertical prefix-extrema，独立于初跑 row-Kadane；全部

- 10 项明确选择的测试通过：1,500 fast/reference、500 穷举行、300
  全场、1,000 coarse 判决、100 独立几何对照，加上 packet/mask/保护/
  费用/篡改/截断及冷 worker；不在供给目录 discover-all。
- 原包 16 保存 synthetic 场重新核对实际载荷和独立矩形最大误差；不是
  新 synthetic optimizer/cold 科学服务。棋盘格 identity/膨胀仍保留。
- 两个只读 AI 副审分别审核证明/查新风险和实际数字/完整费用。数字及
  固定整数合同通过；没有标准化 `EXPERIMENT_AUDIT.json`，不是人类同行

CPU 单线程、GPU0。初跑整体 32.2726 s；fresh replay 35.4856 s。

单进程自峰值 90.62–97.88 MB，不是整树总峰值，也不证明性能支配。

## 5. 机制证据：不再被固定 2×2 边际束缚

事后只读诊断在 16 个保存的非 identity 场上完成 **8,192 行**检查。
固定上一行累计误差时，O(W) coarse-only interval 判据与 DP 的
“该行最少 fine 为零”判决全部一致。这个结论是**条件行层面**，不是
全场必要充分条件，也不是新源预测或全局最优证据。

主线每场 65,536 个 2×2 tile 中，**37,025–59,792** 个改变至少一个
原 row/column margin。这证明实际重建不属于原 fixed-marginal family，
而非只给该对照改名。它不证明新算法原创。细余数少的经验现象只针对
这些固定开发场；没有普适稀疏性定理。

四窗已观察；Tokyo 同窗 metadata 修复；自然 NoData 均 0；工程预算尚

全场/字节最优、跨源留出、扩展尺度、概念原创或 SOTA。
