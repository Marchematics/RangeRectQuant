# RangeRectQuant：让低精度场本身满足未知区域查询

科学栅格压缩之后不仅要能显示，还要能被继续查询。区域面积SUM的
误差取决于像元误差如何一起累积，单点小误差不足以保证大区域；
反过来，先控制累计误差再裁剪越界像元，也可能破坏已经建立的
求和保证。RangeRectQuant把这两件事放进同一次场构造：输出从开始
就位于合法整数范围，同时协调误差，让所有事后矩形共享一份预算。

## 输入、服务与输出

输入是二维整数场X∈{0,…,U}，本实验U=10000，NoData用独立付费mask
标记并在数值场中置0。任意轴对齐矩形R返回valid count及valid SUM；
mask必须精确不变。要求输出Y仍在同一物理范围，且

`max_R |SUM_R(Y)−SUM_R(X)| ≤ epsilon`。

给定步长q，优先构造粗整数，写成Y=qZ+r、0≤r<q。decoder只恢复商Z、
余数r及服务信息，不需要源、误差状态、路径或局部边际。fine位置数
`m(Y)=count(r!=0)`用于解释精度分配，不被当作完整文件大小的替代。

## 将全矩形约束变成可构造的状态约束

设E为Y−X的二维前缀和，边界前缀为0。取B=floor(epsilon/4)，保持
每个E在[−B,B]，矩形误差是四个前缀的交替和，故≤4B≤epsilon。

逐行构造。上一行状态记为u_j，本行前一状态为a，候选新状态为b；
令delta_j=u_j−u_(j−1)、t_j=x_j−delta_j，则

`y_j = t_j + b − a`。

把0≤y_j≤U直接作为转移约束，不进行事后clip。保护位置要求y_j=x_j；
主模式只保护NoData，源零保护是已实现的额外付费消融。复制源行的
路径b_j=u_j总是合法，因此任何合法输入都至少存在完整路径。

## 主实现：先看清合法后缀，再优先删除低位

V_j=[L_j,H_j]表示在位置j之后仍能合法完成整行的整数状态，初始化
V_W=[−B,B]。向后递推：

```text
unprotected: V_(j−1) = [−B,B] intersect [L_j+t_j−U, H_j+t_j]
protected:   V_(j−1) = [−B,B] intersect [L_j−delta_j, H_j−delta_j]
```

未保护点的前驱区间在连续整数b上相接，保护点只平移区间，所以V
始终是准确的整数区间。向前从a选择

`I_j = V_j intersect [a−t_j, a+U−t_j]`。

若I中存在b≡a−t_j(modq)，选最接近0的此类b（tie选较小），从而y_j
是q的倍数；否则选I中最接近0的合法整数，保留细余数。保护点强制
转移。每一步都留在能完成后缀的集合，整行不会因短视选择走入死路。

向后与向前各O(W)，整场O(HW)，额外行工作空间O(W)，不计输入、输出
与传输编码器空间。代码`controls/viable_greedy.py`保持原冻结实现；
QF01原algorithm1现在作为主实现，历史“control”格式标签不另改写。
参考实现最终还构造O(HW)的prefix数组复核，所以这里的O(W)是行
构造空间，不是整个参考程序的峰值内存声明。

## 精确DP的作用与实际率

原条件行DP在相同可行转移上精确最小化fine数，再最小化该行状态
平方和；它是机制oracle，不是全场或字节最优解。开发实验中DP使
fine下降73.29%/70.21%，完整码长却仅比轻量版本再少0.54%/0.85%。
因此选择轻量主实现，而不是增加优化复杂度。

完整传输包含UInt16两字节shuffle+LZMA6的Z/r、NoData mask、可选
source-zero bitmap、geo、固定配置、field digest及checksum。输出本身
仍是可用的合法场；prefix cache由通用查询服务在冷解码后建立。

## 贡献的位置

有界状态、矩阵舍入、区间可达性和DP均继承已有工具，原型来源保留
在用户供给包。这不要求研究从零发明所有组件。我们研究的是：针对
物理范围、未知矩形查询和实际码流的联合合同，如何通过可行性引导
粗/细精度分配，得到有效且轻量的协调量化。相关前作的具体对象差异
与访问范围见`RESEARCH_POSITION_20261001.md`。

单次保证相对本次输入。重复保存不能自动继承原源的一份epsilon，
应保留原packet或明确另外管理累计误差；该边界不改变单次定理。
接下来的检验是固定主实现的地理留出和同合同强控制，而不是以
“每个primitive都必须新造”拒绝开展有价值的实证工作。
