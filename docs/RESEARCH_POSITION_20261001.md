# 研究定位更新：创新不要求从零发明全部工具

按用户最新要求，主线继续推进 **RangeRectQuant：面向任意事后矩形
SUM查询的直接合法低精度场压缩**。我们不再把“必须另造一个非经典
primitive”设为开展留出验证的前提。已有DP、区间可达性、noise shaping
或熵编码不自动否定方法创新；关键是它们是否解决了一个前作没有
完整处理的重要联合问题，并形成可验证的新率—可行性权衡。

## 一篇扎实DCC工作的正面主张

1. **把查询误差作为场构造的约束，而非解码后补救。** 直接产生
   范围内的整数场、保留付费NoData语义，并以一份全局预算控制全部
   矩形SUM。避开先量化前缀再clip导致两种约束相互破坏的路线。
2. **以可行性引导低位删除。** 允许多数像元落在粗格点，仅在当前
   可行路径需要时保留细整数余数；suffix-viable O(HW)实现作为轻量
   主版本，精确条件行DP作为机制oracle/消融。保证来自合法转移与
   有界累计误差，而不是对1024个样本查询的拟合。
3. **用真正交付的场和完整码流证明收益。** 商、余数、mask、geo和
   校验均收费，解码者不持有源或优化状态。四个开发窗口的轻量版本
   已较所列强池减少30.42%/55.77%；下一步检验新地理窗口，而不是
   继续为不到1%的DP差异增加复杂度。

这是**可检验的贡献定位**，不是先行宣布首次、SOTA或录用。精确DP
的>=10%必要性门失败只否定“昂贵DP必不可少”的论证，不否定整个
联合问题、直接场构造或已经测到的实用收益。

## 文献差异必须落到对象和保证上

|邻近工作|可以继承的知识|本研究要证明的具体差异|
|---|---|---|
|[Lyu–Wang二维ΣΔ](https://arxiv.org/html/2005.08487v1)|有界二维状态与mixed difference；已读相关方法|物理in-box整数输出、保护点可行性与付费粗/细表示同时成立；不声称发明有界状态|
|[Asano矩阵rounding](https://dspace.jaist.ac.jp/dspace/bitstream/10119/4906/1/B3022.pdf)|副审本轮读abstract与§§1.1–1.3：floor/ceil rounding及两laminar家族构造|允许更远的合法粗整数和fine escape，以规定的all-rectangle预算为约束、实际码长为结果；不是新discrepancy界|
|[QPET](https://www.vldb.org/pvldb/vol18/p2440-liang.pdf)|QoI预算与correction机制；前轮相关方法已读|同一合法完整场支持编码时未知的矩形集合；需要同合同实流比较，而非只比较文案|
|[TOPIQ](https://arxiv.org/html/2608.26912v1)|已读相关方法：统计误差传播和事后空间QoI预测|这里构造具有确定性全部矩形误差保证的场；统计预测本身不是错误或弱贡献，两者可互补|
|[ICML2026 physics-aligned compression](https://proceedings.mlr.press/v306/ugalde26a.html)|仅official abstract；物理几何量化已有|待全文精读精确排重，不能凭摘要宣布首次或重复|

上述差异是研究对象/保证的定位，不是“未检索到所以原创”的证明。
文献证据不会用于要求每个基础组件全新；也不会因有几篇邻近工作
就停止一个有明确新联合目标和显著真实收益的候选。

## 当前执行选择

保持原协议/数字/负结果不变。新留出阶段固定Cairo、Delhi、New York、
Jakarta原生窗口、原q20/q200和原预算，主实现不再调参。沿用强无损、
SZ3、QPET、MGARD及条件Haar控制；将DP放在同一候选家族内部比较，
不再要求轻量版本“击败它自己”才能被承认为有价值的方法。

重复压缩诊断仅确定流程边界：单次输入合同不能自动继承成原源累计
合同。它不升格成新主线、也不成为留出工作的额外前置门。预算用途
与更多领域证据可以并行补齐，而不是把所有论文工作停在免责清单上。
