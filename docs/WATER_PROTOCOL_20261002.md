# A second bounded scientific quantity

Use the current JRC Global Surface Water occurrence product, version 1.5, covering 1984–2024. The official guide defines integer percentages from 0 through 100, zero as not water and 255 as missing. The distributed TIFFs omit a NoData header tag; the mask follows the documented sentinel. Preserve the failed initial header check in a separate acquisition manifest. The correction changes neither geographic location nor pixels.

Eight locations are frozen from the existing GeoNames coordinates: London, Chicago, Hanoi, Buenos Aires, Bangkok, Rio de Janeiro, Toronto and Nairobi. Native 512-square windows are read on the original 0.00025-degree grid. No resampling or window selection from values is allowed. Each tile URL is present in the official version-1.5 object list; save its byte count, object hash, HTTP headers and complete SHA-256. Credit the European Commission Joint Research Centre and Google, and cite Pekel et al., Nature 540, 418–422 (2016).

This quantity differs from built area. A regional sum is a sum of occurrence percentages; its corresponding mean has error at most epsilon divided by valid-sample count. It is not an area integral on a latitude-dependent grid. Budgets are 5, 10, 25, 50, 100, 250, 500 and 1000 percentage-point sums. Use B=floor(epsilon/4) and q=min(100,max(1,floor(epsilon/5))), fixed before pixel acquisition.

Compare the same 38 native configurations used for built area, with the QPET broad base tolerance set to this product's declared range of 100. Its identity per-sample quantity and four tested absolute tolerances remain fixed. Add native-byte LZMA with raw and row predictors and lossless native-byte PNG. These three lossless settings respect the actual uint8 source representation. This gives 41 external settings and eight RangeRectQuant settings per location, 392 complete files in total. Round native floating outputs to nearest integers, clip to [0,100], preserve missing zeros and pay for this metadata. Files use a distinct percentage-aware native transport; the old built-area packet formats and their saved evidence are unchanged.

Decode every file in a separate source-free process and compute the exact worst rectangular error. Retain exceptions and reject range, mask or regional violations. Report aggregate complete size, paired city-wise wins and changed-value counts at every budget. An exact output is reported as exact, even when produced by a nominally lossy setting. Do not discard uniform or difficult windows, and do not retune parameters after looking at their files.

Primary sources: [official downloads](https://global-surface-water.appspot.com/download), [current product guide](https://storage.googleapis.com/water-world/downloads_ancillary/DataUsersGuidev2024_v.5.pdf), [official object list](https://s3.waw4-1.cloudferro.com/swift/v1/global-surface-water/).
