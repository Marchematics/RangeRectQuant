# RangeRectQuant — bounded fields with accurate regional sums

RangeRectQuant directly constructs an integer scientific field in its physical
range, preserving designated samples and one absolute budget for every rectangular
sum. Backward remaining-row intervals make the construction linear in field size.
The private repository contains source, native cropped data, complete-file results,
failure records, a ten-page DCC article, and saved-data plotting scripts.

## Expanded study (2026-10-02)

- Forty new built-surface locations × three sizes × eight budgets: **960/960**
  main files jointly legal, nontrivial, and smaller than their best eligible
  external files. Aggregate reductions **16.23–72.17%** across the 24 points.
- 6600 attempted files; 6578 source-free decodes; 22 original QPET encoder

  none changes the selected references.
- Eight water-occurrence locations: 392 decoded files. Savings cross from

- Closest mechanisms: 56 files; protected-sample sweep: 40 legal files;
